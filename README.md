# Notes

Source repository for my weblog at <https://xmoooz.github.io/notes/>.

The static HTML pages are generated by [Hugo](https://gohugo.io). Content is
written in Markdown, and the formatting is supplied by the Hugo templates and
CSS stylesheets. The theme is a customized version of
[Lanyon for Hugo](https://github.com/tummychow/lanyon-hugo), inspired by
[Scott Lowe's weblog source](https://github.com/scottslowe/weblog).

## Project layout

```text
archetypes/       Post templates
content/fixed/    Standalone pages (About, Site Archives)
content/post/     Blog posts (add new posts here)
layouts/          Site-specific overrides for the Lanyon theme
static/css/       Site CSS overrides
static/font-awesome/  Font Awesome assets used by the layouts
themes/lanyon-hugo/  Lanyon theme (templates and favicons only)
config.json       Hugo configuration
public/           Generated site (ignored; built by GitHub Actions)
```

The Lanyon theme is vendored at `themes/lanyon-hugo` (based on
[tummychow/lanyon-hugo](https://github.com/tummychow/lanyon-hugo)). Site-specific
customizations live in `layouts/` and `static/` so the theme can be updated
without losing them.

## Local development

```sh
hugo server
```

Then open <http://localhost:1313/notes/>.

## Adding a post

```sh
hugo new content/post/my-post.md
```

Posts use the front matter in `archetypes/post.md`. Set `draft: false` (or
remove the `draft` line) when the post is ready to publish.

## Build

```sh
hugo
```

The generated site is written to `public/`, which is git-ignored. GitHub
Actions runs this same command on every push to `main`.

## Customization

Site title, tagline, author, description, and social settings live in the
`params` section of `config.json`. The About page is a plain Markdown file
under `content/fixed/`.

## Deployment

Pushing to `main` triggers `.github/workflows/hugo.yml`, which builds the site
with Hugo and deploys it to GitHub Pages at
`https://xmoooz.github.io/notes/`. The `baseURL` in `config.json` already
includes the `/notes/` subpath.

One-time setup in the repository: **Settings → Pages → Source → GitHub Actions**.
No build output is committed and no manual deploy step is needed.
